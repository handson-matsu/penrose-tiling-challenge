# ペンローズ・タイリングに挑戦！（第2版）

P3の太い菱形・細い菱形を、辺を選んでつなぐ数学教材です。HTML / CSS / JavaScriptのみで動作し、実行時の外部ライブラリ・外部フォント・通信APIへの依存はありません。GitHub Pagesで配信できます。

## 起動

リポジトリのルートで静的サーバーを起動してください。

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。ES Modulesを使用しているため、HTMLファイルの直接ダブルクリック（`file://`）ではなくHTTP経由で利用してください。ビルドと `npm install` は不要です。

## GitHub Pages

公開する際は、リポジトリの **Settings → Pages → Deploy from a branch** から公開するブランチと `/ (root)` を選択します。すべてのアセットが相対パスなので、プロジェクトサイトのサブディレクトリでも動きます。`.nojekyll` を同梱しています。この開発作業ではコミット・push・公開は行っていません。

提案する英語のリポジトリ説明文：

> An interactive Penrose P3 tiling playground for exploring rhomb matching rules, with touch-friendly controls and high-resolution PNG export.

## 操作

1. 下の菱形の辺（または対応する①〜④）を選ぶと、最初の1枚を配置します。
2. 配置済みの空いている辺と、下の太い／細い菱形の接続辺を選びます。**どちらを先に選んでも構いません。**
3. 2辺がそろうと自動的に回転・平行移動して配置します。配置ボタンはありません。成功したら両方の選択を解除します。
4. 失敗時は作品を変更せず、赤い候補と原因を残します。別の辺を選んで再試行するか、「選択・エラー表示を解除」またはEscapeで解除できます。

背景・タイル内部・辺のどこからでもドラッグ／スワイプして画面移動できます。**移動距離6px超**をドラッグとし、辺の選択や削除を発生させません。一度閾値を超えたら、元の位置に戻ってもクリックにはなりません。ホイール／2本指ピンチ、＋／−で拡大縮小できます。ピンチ後に1本指を残した移動も継続できます。「全体表示」は作品全体を収め、「中央へ」は倍率を保って中央に移します。最後のピースは緑の枠と中心の小さな点で表示します。移動・ズームはタイル座標を変更しません。

「タイル削除」をONにし、任意の1枚をタップして削除します。ホバー／押下中は赤い輪郭で対象を強調します。削除確認は不要です。削除モードでもドラッグとピンチは画面移動です。最初のタイル、中央のタイルも削除でき、穴や複数の連結成分をそのまま維持します。穴の境界も次の接続辺にできます。

Undo / Redo、⌘またはCtrl+Z、Shift+⌘またはCtrl+Zに対応します。削除・「最初から」・見本の読み込みもUndo可能です。Escapeで選択とエラーを解除します。辺とボタンはTab / Enterでも操作できます。スマートフォン幅・タッチ端末では、辺を選ぶ高さ44pxの補助ボタンを表示します。細部は拡大して選んでください。

### エラーと観察用の表示

- 重なりでは候補を半透明の赤、**実際の菱形の交差領域**を濃い赤で示します。重なった全タイルの輪郭を強調し、枚数も表示します。外接矩形の重なりだけではエラーにしません。診断は次の辺選択や明示的な解除まで残るので、移動・ズームして確認できます。
- 既存のマッチング違反は赤い共有辺と違反数で示します。赤い辺を押すとその付近を拡大し、関係する2枚を強調します。違反数のボタンで順に確認できます。低倍率では通常の赤線を細くし、×印を省略します。選択した辺は常に太く、×印付きです。
- 新規候補のマッチング違反も、実際に不一致のある候補辺・既存辺と×印で示します。
- 「菱形の輪郭」は初期OFFです。ONにすると、元の菱形の辺を濃いグレーの破線で表示します。画面ではズームに依存しない1.4pxの線幅で、PNGでは辺長比0.022の線幅で描きます。凹凸なしモードではOFFに戻して操作を無効化します。凹凸ありに戻ったら再びONにできます。PNGにも表示状態を反映します。
- 「配置可能な辺を表示」は、穴を含む外周辺について太い／細いそれぞれ4辺、計8候補を検査します。少なくとも1候補が有効なら緑、すべて無効なら赤。**次の1枚の局所判定で、無限拡張の保証ではありません。** OFF中はこの候補列挙や追加描画を実行しません。ON時は小さな処理単位に分け、配置・削除・モード変更で再計算します。画面移動やズームでは再計算しません。

作品はブラウザの `localStorage` に自動保存します。保存対象は配置データです。モード・表示設定・カメラ・Undo履歴は再読み込み時に初期化されます。ブラウザのストレージを消去すると作品も消えます。自動保存が使えない場合も、その場の作業と画像保存は利用できます。

## モードと教材としての注意

- **凹凸あり**：標準P3の2種類の有向辺によるマッチングを適用します。角のある凹凸／丸い凹凸で種類を区別し、非対称の位置と凹凸の極性で向きを区別します。
- **凹凸なし**：単位辺の普通の菱形を使い、幾何学的な接続と内部の重なりだけを制約します。周期的な菱形格子も作れます。
- モード変更で配置データを変更しません。自由配置から凹凸ありへ変更すると、不一致の共有辺を赤く描きます。既存の違反を自動修正せず、新規接続のすべての接触辺を検査します。
- 青・ピンクの弧とピースの色は独立に表示を切り替えられます。弧は同色・同位置で連続することを観察するための表示です。判定自体は有向辺データを使います。
- 局所ルールへの適合は、無限に拡張できることの保証ではありません。行き詰まりや無限拡張可能性を断定する機能はありません。
- 太い菱形 : 細い菱形の枚数比を表示します。無限P3タイリングの比は黄金比ですが、有限パッチや自由配置でその値になるとは限りません。細い菱形が0枚なら比は「—」です。

## 数学的な定義と検証

各菱形の辺長を1とし、左の鋭角頂点をv0、上をv1、右の鋭角頂点をv2、下をv3とします。画面座標で時計回りです。半角をαとして、頂点は次の通りです。

```text
v0=(-cos α, 0)   v1=(0, -sin α)
v2=( cos α, 0)   v3=(0,  sin α)
太い：α=36°、内角72°/108°
細い：α=18°、内角36°/144°
```

辺iはvi→v(i+1)です。標準P3の一重／二重矢印に相当する2種類を1／2、境界走査に対する向きを+／−で表します。使用する装飾は以下です（全体の矢印反転や種類名の交換は同値な規約です）。

| 菱形 | 辺0 | 辺1 | 辺2 | 辺3 |
| --- | --- | --- | --- | --- |
| 太い | 1− | 2− | 2＋ | 1＋ |
| 細い | 1＋ | 1− | 2＋ | 2− |

共有辺では、両タイルの境界走査が逆向きになるため、**種類が同じ、signが逆**なら一致です。自動配置は追加辺の始点を既存辺の終点、追加辺の終点を既存辺の始点に写す回転と平行移動です。鏡映・拡大縮小は行いません。

凹凸の幅は辺長の約17〜18%、深さは約10%です。＋の凹凸の中心を辺の34%位置、−は66%位置に置き、逆向きに走査するとまったく同じ境界曲線になるようにしています。凹凸を独立した小図形として上に重ねるのではなく、ピースの輪郭そのものを変形します。SVGなのでズームしても滑らかです。衝突判定は、この装飾の土台となる単位菱形の内部に対して行います。適合する装飾は互いに相補的です。

弧は円弧で、細い菱形はv1（青）とv3（ピンク）を中心に半径0.22、太い菱形はv0（青）を中心に半径0.22、v2（ピンク）を中心に半径0.78です。これは各辺上の接点が0.22または0.78になる装飾です。適合する辺で同色の弧の端点が一致することを自動テストしています。

SAT（分離軸定理）で菱形内部の重なりを判定します。全辺一致の共有だけを接続と数え、同一直線上で辺の一部だけが接する配置を拒否します。幾何判定の許容誤差は `1e-7` 辺長、トポロジーの辺キーは座標を `1e-6` 単位に量子化します。新規候補は全ての近隣ピースとの接触を検査します。

### 既知配置

`fixtures/sun-4.json` は、10枚の36°−72°−72°三角形の輪を4回細分化して得た **太い100枚＋細い60枚＝160枚** のsunパッチです。未対合の外周半菱形を除き、辺長を1に正規化しています。`fixtures/generate.mjs` で再生成できます。

幾何配置はRobinson細分化で生成し、装飾の180°の選択だけを共有辺の制約伝播で決めます。装飾ソルバーで菱形の位置を生成したり変更したりはしません。保存済みJSONに対して全ペアの非重複、全共有辺の適合、弧端点の接続を検証します。5回細分化の430枚もテストします。

## PNG保存

「画像保存」から白／透明背景を選び「PNGを保存」。現在の全ピースを余白付きで収め、長辺4096pxで生成します。画面のズーム、画面移動、UIは画像に含めません。表示中の凹凸・弧・色・菱形の輪郭を反映します。エラー候補・交差領域・赤い違反辺・×印・選択辺・配置可能な辺・削除対象の強調・最後のピースの操作用マーカーは含めません。

ファイル名は `penrose-YYYYMMDD-HHMMSS.png`（利用者端末の現地時刻）です。SVG→Image→Canvas→PNG Blobの順で処理します。最大4096²画素に制限し、使用後にCanvasと一時URLを解放します。白背景ではCanvasを不透明な白で先に塗り、外周画素の透明化を防ぎます。iOSのブラウザ設定によっては画像が別画面に開くため、その場合は共有メニュー等で保存してください。

## テスト

Node.js 20以降で実行できます。外部テストパッケージは不要です。

```sh
npm test
# または
node --test tests/*.test.mjs
```

静的サーバー起動中に `http://localhost:8000/tests/browser.html` を開くと、既存3件を含む12件（430枚描画、PNGエンコード・画素、実際のアプリ文書を使うUI回帰テスト）を実行します。UI回帰テストはiframe内で実行し、ブラウザの保存済み配置は実行後に復元します。テスト中は別タブで作品を編集せず、完了表示まで待ってください。ブラウザテストはインターネット接続不要です。

詳細は [TEST_RESULTS.md](TEST_RESULTS.md) を参照してください。レスポンシブ幅の検証は実施していますが、実機のiPad Safariによるピンチ・ダウンロード・長時間操作の確認は未実施です。

共有辺索引は配置が変わった時だけ更新します。画面移動中はSVGのtransformだけを変更します。配置・選択などの更新はrequestAnimationFrameにまとめ、候補判定は不変の配置ごとに作る空間索引で近傍を抽出してから検査します。重なり診断用の交差多角形はSutherland–Hodgman法で求めます。配置可能辺の高速判定と詳細診断は、429枚の穴付きパッチの全外周候補を使い、両モードで同じ可否になることを検証しています。数百枚の利用を想定した設計です。
